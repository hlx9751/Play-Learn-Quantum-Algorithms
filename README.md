# Play-Learn-Quantum-Algorithms
CMAA 6018A - R31 Independent Study projects. As well as a work tracking system. 

## Description
I aim to dive into rigorous quantum algorithm material. All research papers and artistic projects are built upon quantum algorithms, though I used to skip algorithm sections in papers as they were difficult to follow. In this course, I will collect and study quantum algorithms, implement them on Gemini Lab, improve my workflow, and expand my toolkit. If possible, I hope to develop new quantum algorithms.

## Objectives

1. Make a list of Quantum Algorithms, develop a deeper understanding of them various algorithms and how they can be applied within musical practice.
2. Attempt to replicate these algorithms on Gemini Lab and QAC Toolkit.
3. produce an (maybe not complex) algorithm as the basis for my artworks or papers.
4. Optional: Artistic-related Quantum Algorithms learning path.

## Final deliverable

1. GitHub repositories with Codebase, Dataset, and Application. Specific content include below:

 - Quantum Algorithms study notes
 - Experiment file and data recorded
 - Artistic practice project
 - Journals, Documents, Assets

2. A presentation on slides at the end of semester, share to all xQAP members.
